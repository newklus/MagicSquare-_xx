# Mom Test 질문 10개 — MagicSquare_XX

## 페르소나

4×4 격자, 빈칸 2개(0), 1~16, 행·열·대각선 합 34 맞추는 학습자

---

## 1. 마지막으로 틀렸을 때

**Q1.** ✅  
마지막으로 4×4 마방진에서 빈칸 2개를 채웠는데 틀렸다는 걸 알게 된 건 언제였고, 그때 격자에 숫자를 어떻게 배치해 두었어?

**Q2.** ❌  
「대각선 검증을 자동으로 알려주는 기능 있으면 실수 줄일 수 있을 것 같아?」  
→ **왜 나쁜지:** 미래·가설·솔루션을 묻는 질문이라 "좋을 것 같아"만 나온다.  
→ **✅ 고친 버전:** 마지막으로 대각선 조건을 놓쳤다는 걸 알아챈 순간, 그때까지 행·열은 맞다고 생각했어?

---

## 2. 검증/확인 비용

**Q3.** ✅  
마지막으로 행·열·대각선 합 34를 맞췄는지 확인할 때, 어떤 순서로 어떤 방법으로 검증했고, 그 과정에 대략 몇 분 걸렸어?

**Q4.** ❌  
「한 번에 모든 줄 합을 확인해 주는 도구 있으면 시간 절약될까?」  
→ **왜 나쁜지:** 도구 유무를 가정하고 "절약될까?"를 묻어 찬성만 유도한다.  
→ **✅ 고친 버전:** 마지막으로 답이 맞는지 확인하려고 어디까지 손으로 검산했고, 그다음에 뭘 했어?

---

## 3. 포기·중단 순간

**Q5.** ✅  
마지막으로 마방진 풀다가 그날 그만둔 직전, 정확히 무슨 일이 있었고 그때 몇 분째였어?

**Q6.** ❌  
「20분 넘게 걸리면 보통 포기해?」  
→ **왜 나쁜지:** 일반화·습관 가정 질문이라 실제 사례 대신 "보통은" 답이 나온다.  
→ **✅ 고친 버전:** 마지막으로 풀다 멈춘 날, 포기하기 직전에 마지막으로 한 행동이 뭐였어?

---

## 4. 같은 문제를 다시 풀 때

**Q7.** ✅  
한번 틀렸던 그 문제를 나중에 다시 풀어본 적 있어? 있다면 첫 시도 때랑 뭐가 달라졌고, 결과는 어땠어?

**Q8.** ❌  
「틀린 문제를 다시 풀 수 있는 반복 연습 기능 있으면 도움 될까?」  
→ **왜 나쁜지:** 기능 제안을 섞어 "도움 될 것 같다"는 찬성만 받는다.  
→ **✅ 고친 버전:** 틀린 뒤 처음부터 다시 시작했을 때, 이전에 쓴 숫자 배치를 그대로 썼어 아니면 격자를 비우고 새로 썼어?

---

## 5. 다른 사람에게 설명/공유할 때

**Q9.** ✅  
마지막으로 누군가에게 이 4×4 마방진(빈칸 2개) 풀이를 설명해 준 적 있어? 그때 상대가 가장 헷갈려 한 부분이 뭐였어?

**Q10.** ❌  
「풀이 과정을 친구에게 공유할 수 있는 기능 필요해?」  
→ **왜 나쁜지:** "필요해?"는 기능 수요를 직접 묻는 Mom Test 위반이다.  
→ **✅ 고친 버전:** 마지막으로 누군가에게 풀이를 보여줄 때, 종이·채팅·사진 중 뭘로 어떻게 전달했어?

# Mom Test 워크북 — MagicSquare_XX (STEP 1)

## 페르소나

4×4 부분 마방진을 손으로/코드로 다루는 학습자

---

## 인터뷰 답변 (과거 사실)

| 질문 | 답변 |
|------|------|
| 마지막으로 4×4 부분 마방진을 다룬 시점과 시작 이유 | 2달 전, 심심해서 |
| 그날 실제로 한 일 (처음~그만둘 때까지) | 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서 20분 날렸다 |
| 대각선 빼먹은 걸 알아챈 뒤 행동 | 다시 처음부터 시작했어 |
| 처음부터 다시 한 뒤 결과 | 못 맞췄어. 20분 걸렸어 |
| 못 맞춘 뒤 마지막 행동 | 답을 찾아봤어 |
| 답 확인 방법 및 이후 | AI LLM을 통해서 확인했고 다른 문제는 안 풀었어 |
| 다른 문제 안 푼 이유 | 피곤해서. 머리가 안 돌아갔어 |

---

## 표면 문제 (금지 — 솔루션 섞인 문장)

「4×4 부분 마방진 **검증·풀이 프로그램**을 만들면, 대각선 빼먹음 같은 실수를 막고 학습 시간을 줄일 수 있다.」

---

## 진짜 문제 (한 문장)

손으로 4×4 부분 마방진을 풀 때 **행·열·대각선 합을 모두 맞췄는지 스스로 판정하기 어렵고**, 조건 하나를 놓치면 **20분 넘게 쓴 뒤 처음부터 다시**해야 하는데 **그래도 못 맞추면** 답을 확인한 뒤 **피로 때문에 그날 학습을 이어가지 못한다**.

---

## Mom Test 증거 3줄

1. 「빈칸 2개 넣고 행·열·대각선 합 맞췄는데 **대각선 하나를 빼먹어서 20분 날렸다**」
2. 「**다시 처음부터 시작했어**」 → 「**못 맞췄어. 20분 걸렸어**」
3. 「**AI LLM**을 통해서 확인했고 **다른 문제는 안 풀었어**」 / 「**피곤해서. 머리가 안 돌아갔어**」

---

## 인사이트 요약

- **판정 불확실성**: 행·열은 맞췄다고 생각했으나 대각선 조건 누락
- **비용**: 잘못된 판정 → 20분+ 낭비 → 처음부터 재시작
- **학습 중단**: 2차 시도 실패 → LLM으로 답 확인 → 피로로 세션 종료, 추가 문제 미진행
